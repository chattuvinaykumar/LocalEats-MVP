# LocalEats-MVP
🍽️ LocalEats

LocalEats is a modern food ordering and restaurant management platform designed to help local restaurants connect directly with customers while reducing dependency on high-commission delivery marketplaces.

🚀 Features

Customer Features

- Browse restaurants and menus
- Search food items and restaurants
- Add items to cart
- Secure checkout flow
- Saved delivery addresses
- Favorites management
- Notifications
- Order tracking and history
- Profile management
- Payment method management

Restaurant (Merchant) Features

- Restaurant registration and onboarding
- Menu management
- Offer and promotion management
- Business dashboard
- Order management
- Profile customization
- Banner and promotional image uploads
- Revenue and performance insights

Platform Features

- Responsive web application
- Supabase-powered backend
- Secure authentication
- Real-time data management
- Cloud deployment with Vercel
- Mobile-friendly design

🛠️ Tech Stack

Frontend

- React Native Web
- Expo
- Expo Router
- TypeScript

Backend

- Supabase
- Authentication
- Database Storage

Deployment

- Vercel
- GitHub

🎯 Vision

LocalEats aims to empower local restaurants by providing a simple and affordable digital ordering platform.

Unlike traditional food delivery marketplaces that charge high commissions, LocalEats is designed around a restaurant-friendly model that supports direct customer engagement and sustainable business growth.
